# Documentation Layout

This directory holds human-readable project material.

- `journal/`: dated status entries and compiled journal PDFs.
- `notes/`: background derivations and longer calculation notes.
- `plans/`: implementation plans and design notes for script versions.
- `audits/`: reserved for future math, code, and claim-audit reports.

Generated build byproducts should go under `artifacts/latex/` unless a tool
requires them next to the source.

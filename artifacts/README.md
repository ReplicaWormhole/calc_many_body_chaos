# Artifacts Layout

This directory stores generated or archival material that should not clutter
the project root.

- `latex/`: LaTeX build byproducts grouped by source area.
- `legacy_output/output_2026-05-20/`: generated output tree moved from the
  former root-level `output/` contents.
- `generated/`, `reports/`, `topology_images/`, `wolfram_metadata/`: reserved
  locations for future generated data.

The active output directory for new runs remains `output/`.
